Given some compare function
compare: t \* t -&gt; order

Int.compare, String.compare

Define
L : t list is sorted if
either L is []
or L is x::xs such that
xs is sorted and compare(x,y) =&gt; LESS or EQUAL for every y in xs

split: t list -&gt; t list \* t list
REQ: true
ENS: split L =&gt; (A,B) s.t. L is equivalent to a permutation of A @ B

|                       |         |
|-----------------------|---------|
| length(A) - length(B) | &lt;= 1 |

```sml
fun split ([]: t list): t list * t list = ([], [])
  | split [x] = ([x], [])
  | split (x::y::rest) = let val (A, B) : t list * t list = split rest in (x::A, y::B) end;
```

The work of split:
Wsplit(0) = c_0
Wsplit(1) = c_1
Wsplit(n) = c_2 = Wsplit(n-2), n &gt;= 2
c_2 + c_2 + c_2 + ... c_0 or c_1
O(n)

merge: t list \* t list -&gt; t list
REQUIRES: A is sorted and B is sorted
ENSURES: merge(A, b) is a sorted permutation of A @ B

```sml
fun merge([]: t list, B: t list): t list = B
  | merge(A, []) = A
  | merge(x::xs, y::ys) = case compare(x,y) of
                          LESS => x::merge(xs, y::ys)
                        | EQUAL => x::y::merge(xs, ys)
                        | GREATER => y::merge(xs, y::ys);
```

Wmerge(0,m) = c_0 for all m &gt;= 0
Wmerge(n,0) = c_1 for all n &gt;= 0
Wmerge(n,m) = c_2 + Wmerge(n-1,m) or c_2' + Wmerge(n-1,m-1) or c_2'' + Wmerge(n,m-1)

s = m+n
s &gt;= 0 and at least one of n is 0,
Wmerge(s) = k_0 (k_0 = max{c_0),c_1})
s &gt;= 2 Wmerge(s) = c_2 + Wmerge(s-1) or c_2' + Wmerge(s-2) or c_2'' + Wmerge(s-1)

Wmerge(s) = k_1 + Wmerge(s-1)
So this is O(s)

Back to Merge sort

```sml
fun msort ([]: t list): t list = []
  | msort [x] = [x]
  | msort L = let val (A: t list, B: t list) = split L in merge(msort A, msort B) end;
```

Wmsort(0) = c_0
Wmsort(1) = c_1
Wmsort(n) = c_2 + Wsplit(n) + Wmsort(n/2) + Wmsort(n/2) + Wmerge(n) &lt;= kn + 2Wmsort(n/2)

This is bounded by knlogn
Work: nlogn
Span: n
