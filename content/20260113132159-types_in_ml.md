## Definition {#definition}

A type is a prediction about the kind of value an expression must have if it ends up reducing to a value.

SML never evaluates an ill-typed expression.

Example:

Type: int
Values: \\(\dots,\sim1,0,1,\dots\\)
Expressions: \\(e\_1 + e\_2\\), etc.

Base types: int, real, bool, char, string
Constructed types:

-   product types
-   function types
-   user-defined types


## Typing Rules {#typing-rules}

\\((e\_1,e\_2) \Rightarrow t\_1\*t\_2\\) if
\\(e\_1\Rightarrow t\_1\\) and
\\(e\_2 \Rightarrow t\_2\\)

Examples:
(3\*4, 1.1+7.2, \text{true})
\\(\hookrightarrow\\) (12, 8.3, \text{true})

(5 \text{ div } 0, 2+1): int \\(\*\\) int
but has no value

(2, (true, "a"), 3.1) has type int \* (bool \* string) \* real
this is different than int \* bool \* string \* real


## Type Definitions {#type-definitions}

```sml
type float = real
type point = float*float
val p: point = (1.0, 2.0)
```
