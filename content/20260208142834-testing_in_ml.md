Tests are written like `Test.function_name` where `function_name` is actually just the output type.

`val () = Test.function_name (name, expected, actual)`

i.e. for testing factorial function

```sml
val () = Test.int("fact_4_test", 24, fact 4)
val () = Test.string_int (* for tuples *)
```


## Val Tests {#val-tests}

More convenient to write but less "formal"

```sml
val 24 = fact 4
val true = not (false)
```
