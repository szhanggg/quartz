Type t list for any type t
Values [v1, .., vn] with each a value of type t
n &gt;= 0 (By n=0 we mean the empty list, written [] or nil)

Expressions:
All the values e::es, with e:t and es:t list
For example 1::[2,3] which gives the list [1,2,3] : int list
:: is pronounced cons

1::[2,3] and [1,2,3] are the same as 1::2::3::nil

[] : t list
e::es : t list
if e:t and es:t list

[] is a value (pronounced "nil") same as nil

e::es =&gt; e'::es
if e =&gt; e'

v::es =&gt; v::es'
if v is a value es =&gt; es'

Left to right evaluation

Can use list structure as patterns, with variable bindings to different parts of the list

```sml

fun length ([]:int list): int = 0
  | length (x::xs) = 1 + length(xs);
```

Theorem: length is total

We need to show that length L reduces to some value for all values L: int list
Inductive Case: L = x::xs for some values x:int \* xs:int list

Induction Hypothesis:
length xs \\(\hookrightarrow\\) v', some value v'
