```sml
datatype extint = NegInf | Finite of int | PosInf;
#+end_src sml

How to use this in code:

#+begin_src sml
fun minList([]: int list) : extint = PosInf
   | minList(x::xs) = (case minList(x) of
                            PosInf => Finite(x)
                          | Finite(y) => Finite(Int.min(x, y))
                          | _ => raise Fail "unreachable");
#+end_src sml

Example for trees:
#+begin_src sml
datatype tree = Empty | Node of tree*int*tree;
```

If you don't put the Empty base case, you would never be able to construct a tree.

```sml
val t1: tree = Node(Empty,1,Node(Empty,2,Empty));
```

(The different possibilities of a datatype are constructors)

```sml
fun depth(Empty: tree): int = 0
  | depth(Node(l,x,r)) = 1 + Int.max(depth l, depth r);
```

Proof that depth is total.

Show depth(t) \\(\hookrightarrow\\) Some value for all values t.
Base Case: t = Empty
depth(t) \\(\hookrightarrow\\) 0 (1st clause depth.)

Induction Step: t = Node(l,x,r) for some values
IH: depth(l) \\(\hookrightarrow v\_l\\) for some value of type int.
depth(r) \\(\hookrightarrow v\_r\\) for some value of type int.

```sml
datatype tree = Leaf of int | Node of tree*tree;

fun flatten (Leaf(x): tree): int list = [x]
  | flatten (Node(l,r)) = flatten(l) @ flatten(r);

fun flatten2 (Leaf(x): tree, acc: int list): int list = x::acc
  | flatten2 (Node(t1,t2), acc) = flatten2(t1,flatten2(t2,acc));

(* The outer call is a tail call, the inner is not. *)
```
