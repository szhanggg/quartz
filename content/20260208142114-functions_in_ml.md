A function maps values of one type to values of another type. Functions can be treated as values.

Functions can be [total]({{< relref "20260208142446-totality_in_ml.md" >}}).

The 5-step method to declaring functions is:

1.  Include comments that provide the function invariants and specifications.
2.  Includes a REQUIRES specification.
3.  Includes an ENSURES specification.
4.  Declares the function using a keyword and an identifier.
5.  Create [test cases]({{< relref "20260208142834-testing_in_ml.md" >}}) for the function.

<!--listend-->

```sml
(* <function_name>: <type> -> <type>
REQUIRES: ...
ENSURES: ...
*)

fun <function_name> (<param> : <type>) : <type> = <body>
<test_cases>)
```

Functions are also values!
