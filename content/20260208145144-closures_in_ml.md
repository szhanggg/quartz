A closure consists of two parts.

1.  A lambda expression (code) that defines the function, with NO return type. `fn (<param>: <type>) => <body>`.
2.  An environment, which consists of all of the previous bindings of variables when the function was declared. `[3/x, 5/y, false/z]`.
