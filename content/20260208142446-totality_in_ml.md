We say a function \\(f: X \to Y\\) is total if \\(f\\) reduces to a value and \\(f(x)\\) reduces to a value for all values \\(x\\) in the domain \\(X\\).

Totality is used to describe **function behavior**. Valuability is used to describe expressions.

Functions are always valuable, but they are not necessarily total.


## Totality Citations {#totality-citations}

If the expression is a function call you need to cite totality.

You **do not** need to cite totality of a function when you are simply stepping through the function (unless the function calls itself).

Example:

```sml
fun foo [] = 0
  | foo (x::xs) = x + foo(xs)
fun boo [] = []
  | boo (x::xs) = x::(boo xs)
```

`foo (boo(x::xs))` \\(\equiv\\) `foo(x::(boo xs)` does not need a totality citation.

However, `foo (x::(boo(xs)))` \\(\equiv\\) `x + foo(boo(xs))` needs a totality citation.
