## Definition {#definition}

A function f maps between two types X, Y
\\(f: X \rightarrow Y\\)
A function f is total if f reduces to a value and f(x) reduces to a value for all values x in X.
Sample function code:

```sml
(* square : int -> int
   REQUIRES: true
   ENSURES: square(x) evaluates to x * x
*)

fun square (x : int) : int = x * x

(* Testcases: *)

val 0 = square 0
val 49 = square 7
val 81 = square (~9)
```

```sml
fun fact (0 : int) : int = 1
  | fact (n : int) : int = n * fact(n - 1)
```

vertical bar allows for separate casing


## Closures {#closures}

Function declarations also create value bindings:

```sml
fun square (x : int) : int = x * x
```

binds the identifier square to a closure.

The closure consists of two parts:

-   A lambda expression (code):
    fn (x : int) =&gt; x \* x
-   An environment (all prior bindings)
    What do the variables mean, what is times, etc.

Thus, square gets bound to the closure and the environments


## Function Application {#function-application}

We look at
e2 e1 (function e2 applied to e1)


### Typechecking rules {#typechecking-rules}

(fn (x: t1) =&gt; body) : t1 -&gt; t2
if body : t2 assuming x : t1

(fn (x: int) =&gt; x) : int -&gt; int

e2 e1 : t2
if e2 : t1 -&gt; t2
and e1 : t1


### Evaluation Rules {#evaluation-rules}

1.  Reduce e2 to a (function) value
    This is a closure containing a lambda expression as well as the environment env
2.  Reduce e1 to a value v.
3.  Extend env with the binding [v/x]
4.  Evaluate body in this extended environment
    If evaluation of body produces a value w, return w in the original calling environment

Example:
area (2.1 + 1.9)
\\(\Rightarrow\\) [3.14159/pi]
(fn (r:real) =&gt; pi\*r\*r) (2.1 + 1.9)
\\(\Rightarrow\\) [3.14159/pi]
(fn (r:real) =&gt; pi\*r\*r) 4.0
\\(\Rightarrow\\) [3.14159/pi][4.0/r] pi\*r\*r
\\(\Rightarrow\\) 50.26544

So
area (2.1 + 1.9) \\(\hookrightarrow\\) 50.26544


### Function Clauses and Pattern Matching {#function-clauses-and-pattern-matching}

```sml
fun fact(0: int):int = 1
  | fact(n:int):int = n*(fact(n-1));
```

There are two function clauses in this code.
The first clause starts with the keyword "fun"
while the second clause starts with the "or bar" |

When SML evaluates an expression of the form fact(value), SML tries to match value against each pattern in sequential order.

For a general form

```sml
fun f p1 = e1
  | f p2 = e2


  | f pk = ek
```

If f : t -&gt; t' then
each pattern pj must match type t and each expression ej must match type t'.

When evaluating f(v) and no pattern matches v, there will be a fatal runtime error.
SML will give a "non-exhaustive warning" if {pj} does not cover all possibilities.
SML will raise a fatal error when f is declared if there are redundant patterns.


### Functions as First-Class Values {#functions-as-first-class-values}

We can pass functions as arguments

```sml
fun sqrf (f : int -> int, x : int) : int = square(f(x));

val 36 = sqrf (fn (n:int) => n+2, 4);
```
