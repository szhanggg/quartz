Since there is no mutation of state in SML, you must use recursion in order to create change.
Recursion can be proven correct by standard, strong, and structural induction.


## Standard Induction {#standard-induction}

Consider the function `power`.
\#+begin_src sml
(\* power: int \* int -&gt; int
REQUIRES: k &gt;= 0
ENSURES: power(n, k) ==&gt; n^k, defining 0^0 = 1
\*)
fun power(n : int, 0 : int) : int = 1

|                                                    |
|----------------------------------------------------|
| power(n : int, k : int) : int = n \* power(n, k-1) |

\#+end_src sml

We can prove the correctness of `power` by proving a "theorem".

-   Theorem: for all values `n: int * k`, with \\(k \ge 0\\), `power (n, k)` \\(\hookrightarrow n^k\\).
-   Proof: Standard induction on \\(k\\).
-   Base Case: \\(k = 0\\). This comes from the first clause.
-   Induction Step: For some value `k: int`, \\(k \ge 0\\), need to show that `power(n,k+1)` \\(\hookrightarrow n^{k+1}\\) for all values `n: int`.
-   Induction Hypothesis: For some \\(k \ge 0\\), `power(n,k)~$\hookrightarrow n^k$ for all values ~n: int`.
