## Definition {#definition}

For now, a pattern can be any of the following:

-   A constant (e.g., 3, true, "abc", no reals)
-   a variable
-   a tuple of subpatterns
-   the wildcard _ (which matches anything)

Patterns always appear on the left hand side.
Patterns must be linear, no variable can appear more than twice in any one pattern.

Patterns can appear in declarations

```sml
val (k,r) : int * real = (2, 3.14)
```

You can throw away fields/variables with an underscore.

Patterns can appear in declarations: For example

```sml
(* fibb : int -> int * int
   REQUIRES: n >= 0
   ENSURES: fibb(n) ==> (f(n), f(n-1))
   with f(n) being the nth fibonacci number.
*)

fun fibb (0:int):int*int = (1,0)
  | fibb n =
    let
        val (a:int, b:int) = fibb(n-1)
    in
        (a+b, a)
    end

val (21, 13) = fibb 7
```


## Case Expressions {#case-expressions}

```sml
(case e of
     p1 => e1
   | p2 => e2

   | pk => ek)
```

can be used to avoid nested if-else
