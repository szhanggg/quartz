<div class="definition">

A **metric space** is a non-empty set \\(X\\) along with a metric \\(d: X \times X \to [0, \infty)\\) such that:

1.  \\(\forall x,y \in X\\), \\(d(x, y) = 0\\) if and only if \\(x = y\\).
2.  \\(\forall x,y \in X\\), \\(d(x,y)=d(y,x)\\).
3.  \\(\forall x,y,z \in X\\), \\(d(x,z) \leq d(x,y) + d(y,z)\\).

</div>

<div class="definition">

A normed vector space is a Vector Space \\(V\\) along with a norm \\(||\cdot||: V \to [0, \infty)\\) such that:

1.  \\(||\alpha\vec{v}|| = |\alpha|||\vec{v}||\\)
2.  \\(||\vec{u}+\vec{v}|| \leq ||\vec{u}|| + ||\vec{v}||\\)

</div>

<div class="remark">

If \\((X, ||\cdot||)\\) is a norm space, then \\((X, d)\\) is a metric space where \\(d(x,y) = ||\vec{x}-\vec{y}||\\).

</div>

From here we see our first non-trivial example of a metric space.

<div class="exampleblock">

\\(X=\mathbb{R}^d\\), \\(p\in(0,\infty)\\). Define

1.  \\(|x|\_p = (\sum|x\_i|\_p)^{1/p}\\) if \\(p < \infty\\).
2.  \\(|x|\_p = \max\_{1 \leq i \leq d} |x\_i|\\) if \\(p = \infty\\)

</div>

Claim: \\((\mathbb{R}^{d}, |\cdot|\_p)\\) is a normal vector space if and only if \\(p \ge 1\\).

This is equivalent to showing that \\(d(x,y)=|x-y|\_p\\) defines a metric on \\(\mathbb{R}^{d}\\) if and only if \\(p \ge 1\\).
