<div class="definition">

A **metric space** is a non-empty set \\(X\\) along with a metric \\(d: X \times X \to [0, \infty)\\) such that:

1.  \\(\forall x,y \in X\\), \\(d(x, y) = 0\\) if and only if \\(x = y\\).
2.  \\(\forall x,y \in X\\), \\(d(x,y)=d(y,x)\\).
3.  \\(\forall x,y,z \in X\\), \\(d(x,z) \leq d(x,y) + d(y,z)\\).

</div>

<div class="definition">

A normed vector space is a V.S. V along with a norm \\(||\cdot||: V \to [0, \infty)\\) such that:

1.  \\(||\alpha\vec{v}|| = |\alpha|||\vec{v}||\\)
2.  \\(||\vec{u}+\vec{v}|| \leq ||\vec{u}|| + ||\vec{v}||\\)

</div>

<div class="remark">

If \\((X, ||\cdot||)\\) is a norm space, then \\((X, d)\\) is a metric space where \\(d(x,y) = ||\vec{x}-\vec{y}||\\).

</div>
