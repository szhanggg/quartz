The base types in ML include `int, real, bool, char, string`.
There are also product types, also known as tuples, and function types.
You can also define your own types.

Product types are constructed with `*`.

<div class="remark">

Nested tuples have different types than unnested tuples with the same number of elements and equal types.

`int * (char * bool)` is not the same type as `int * char * bool`.

The first would have values of the form (5, ('a', true)) while the second of the form
(5, 'a', true).

</div>
